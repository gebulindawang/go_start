# 06 - 错误处理

## 1. Go 的错误处理哲学

### Java 写法
```java
try {
    doSomething();
} catch (IOException e) {
    e.printStackTrace();
} finally {
    cleanup();
}
```

### Go 写法

```go
// Go 没有 try-catch，错误作为返回值
result, err := doSomething()
if err != nil {
    fmt.Println("出错:", err)
    return
}
fmt.Println("结果:", result)
```

> Go 的核心思想：**错误是值，应该被显式处理**，不要忽略。

## 2. error 类型

`error` 是一个内置接口：

```go
type error interface {
    Error() string
}
```

### 创建错误

```go
import "errors"

// 方式 1：errors.New
err := errors.New("文件不存在")

// 方式 2：fmt.Errorf（支持格式化）
err := fmt.Errorf("用户 %s 不存在", name)
```

## 3. 返回错误的标准模式

```go
func Divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("除数不能为 0")
    }
    return a / b, nil
}

// 调用
result, err := Divide(10, 0)
if err != nil {
    fmt.Println("错误:", err)
    return
}
fmt.Println("结果:", result)
```

> 约定：错误总是作为**最后一个返回值**，成功时返回 `nil`。

## 4. 错误处理的常用写法

### 立即检查（最常用）

```go
file, err := os.Open("config.txt")
if err != nil {
    log.Fatal(err)  // 打印错误并退出
}
defer file.Close()
```

### if 初始化语句（Go 特色）

```go
if err := doSomething(); err != nil {
    fmt.Println("出错:", err)
    return
}
```

### 逐层返回

```go
func readFile(path string) ([]byte, error) {
    file, err := os.Open(path)
    if err != nil {
        return nil, err  // 直接返回错误
    }
    defer file.Close()

    data := make([]byte, 1024)
    n, err := file.Read(data)
    if err != nil {
        return nil, err
    }
    return data[:n], nil
}
```

## 5. 自定义错误类型

```go
type UserError struct {
    Code    int
    Message string
}

// 实现 error 接口
func (e *UserError) Error() string {
    return fmt.Sprintf("[code=%d] %s", e.Code, e.Message)
}

func FindUser(id int) (string, error) {
    if id <= 0 {
        return "", &UserError{
            Code:    400,
            Message: "无效的用户 ID",
        }
    }
    return "Tom", nil
}

// 使用
name, err := FindUser(-1)
if err != nil {
    // 类型断言获取自定义错误
    if ue, ok := err.(*UserError); ok {
        fmt.Println("错误码:", ue.Code)
        fmt.Println("错误信息:", ue.Message)
    }
    return
}
```

## 6. 错误包装（Go 1.13+）

```go
import "fmt"

var ErrNotFound = errors.New("用户不存在")

func GetUser(id int) (string, error) {
    if id < 0 {
        // 包装错误，保留上下文
        return "", fmt.Errorf("GetUser(%d) failed: %w", id, ErrNotFound)
    }
    return "Tom", nil
}

// 调用方解包
name, err := GetUser(-1)
if errors.Is(err, ErrNotFound) {
    fmt.Println("用户不存在错误")
}
```

- `errors.Is(err, target)`：判断 err 是否等于 target（或其包装链中包含 target）
- `errors.As(err, &target)`：从错误链中提取特定类型

## 7. defer（延迟执行）⭐

`defer` 用于在函数返回前执行清理操作，类似 Java 的 `finally`。

```go
func ReadFile() {
    file, err := os.Open("test.txt")
    if err != nil {
        return
    }
    defer file.Close()  // 函数返回前自动调用

    // 其他操作...
}
```

### defer 特点

1. **LIFO 顺序**（后进先出）
2. **参数立即求值**，但延迟执行

```go
func main() {
    defer fmt.Println("1")
    defer fmt.Println("2")
    defer fmt.Println("3")
    fmt.Println("main")
}
// 输出:
// main
// 3
// 2
// 1
```

### defer 用途

- 关闭文件
- 释放锁
- 关闭数据库连接
- 关闭 HTTP 响应体

```go
// 典型用法
resp, err := http.Get("https://example.com")
if err != nil {
    return err
}
defer resp.Body.Close()
```

## 8. panic 和 recover

`panic` 类似 Java 的 `RuntimeException`，用于严重错误。

### panic

```go
func main() {
    fmt.Println("start")
    panic("出大事了！")  // 程序崩溃
    fmt.Println("end")  // 不会执行
}
```

### recover（只能在 defer 中使用）

```go
func safeRun() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("捕获 panic:", r)
        }
    }()

    panic("something went wrong")
}

func main() {
    safeRun()
    fmt.Println("程序继续运行")
}
```

### 何时使用 panic？

| 场景 | 使用 |
|------|------|
| 程序初始化失败（如读取必要配置） | panic |
| 不可能发生的状态（防御性编程） | panic |
| 数组越界、空指针等 | runtime 自动 panic |
| 普通的业务错误 | **不要**用 panic，用 error |
| 文件不存在、网络失败 | **不要**用 panic，用 error |

> **原则**：库代码不要 panic，让调用方决定如何处理错误。

## 9. 实战示例

```go
package main

import (
    "errors"
    "fmt"
    "log"
)

var (
    ErrInvalidInput = errors.New("invalid input")
    ErrNotFound     = errors.New("not found")
)

func GetUser(id int) (string, error) {
    if id <= 0 {
        return "", fmt.Errorf("GetUser: %w", ErrInvalidInput)
    }
    if id > 100 {
        return "", fmt.Errorf("GetUser: %w", ErrNotFound)
    }
    return "Tom", nil
}

func main() {
    name, err := GetUser(-1)
    if err != nil {
        if errors.Is(err, ErrInvalidInput) {
            log.Println("参数错误:", err)
            return
        }
        if errors.Is(err, ErrNotFound) {
            log.Println("用户不存在:", err)
            return
        }
        log.Println("未知错误:", err)
        return
    }
    fmt.Println("用户:", name)
}
```

```go
func timeCost(name string) func() {
    start := time.Now()
    return func() {
        fmt.Printf("%s 耗时: %v\n", name, time.Since(start))
    }

}
```
