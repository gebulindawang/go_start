# 05 - 结构体与接口

## 1. 结构体（struct）

Go 没有 class，用 struct 表示自定义数据结构。

### Java 写法
```java
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String greet() {
        return "Hi, I'm " + name;
    }
}
```

### Go 写法

```go
type Person struct {
    Name string  // 字段大写开头 = 公开（public）
    Age  int     // 小写开头 = 私有（包内可见）
}

// 创建
p1 := Person{Name: "Tom", Age: 18}   // 按字段名（推荐）
p2 := Person{"Tom", 18}              // 按顺序
p3 := new(Person)                    // 返回 *Person，字段为零值
p3.Name = "Jerry"

// 访问字段
fmt.Println(p1.Name)
```

### 可见性规则 ⭐

- **大写开头**：公开（其他包可访问），如 `Name`、`Age`
- **小写开头**：私有（仅当前包可访问），如 `name`、`age`

> 类比 Java：相当于自动的 public/private，但作用范围是**包级别**，不是类级别。

## 2. 构造函数（Go 没有构造函数）

Go 用工厂函数模拟构造函数：

```go
type Person struct {
    Name string
    Age  int
}

// 工厂函数（约定俗成命名为 NewXxx）
func NewPerson(name string, age int) *Person {
    return &Person{
        Name: name,
        Age:  age,
    }
}

// 使用
p := NewPerson("Tom", 18)
```

## 3. 结构体嵌套（组合优于继承）

Go **没有继承**，通过嵌套实现代码复用。

### Java 继承
```java
class Student extends Person {
    private String school;
}
```

### Go 组合

```go
type Person struct {
    Name string
    Age  int
}

type Student struct {
    Person        // 匿名嵌套（"继承" Person 的字段）
    School string
}

// 使用
s := Student{
    Person: Person{Name: "Tom", Age: 18},
    School: "清华",
}

// 字段提升：可以直接访问 Person 的字段
fmt.Println(s.Name)  // Tom（等价于 s.Person.Name）
fmt.Println(s.Age)   // 18
```

### 方法也会提升

```go
func (p Person) Greet() {
    fmt.Println("Hi, I'm", p.Name)
}

s := Student{Person: Person{Name: "Tom"}}
s.Greet()  // OK，可以直接调用
```

## 4. 接口（interface）

### Java 写法
```java
public interface Animal {
    String speak();
}

public class Dog implements Animal {
    public String speak() {
        return "汪汪";
    }
}
```

### Go 写法（隐式实现）⭐

```go
// 定义接口
type Animal interface {
    Speak() string
}

// 实现接口（不需要 implements 关键字！）
type Dog struct{}

func (d Dog) Speak() string {
    return "汪汪"
}

type Cat struct{}

func (c Cat) Speak() string {
    return "喵喵"
}

// 使用
func MakeSound(a Animal) {
    fmt.Println(a.Speak())
}

func main() {
    MakeSound(Dog{})  // 汪汪
    MakeSound(Cat{})  // 喵喵
}
```

### 核心区别

| 特性 | Java | Go |
|------|------|-----|
| 实现方式 | 显式 `implements` | **隐式**（只要方法签名匹配） |
| 设计理念 | "是什么" | "能做什么" |
| 耦合度 | 紧（必须知道接口） | 松（实现方不知道接口存在） |

> Go 的接口设计哲学：**鸭子类型** —— "如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子"。

## 5. 空接口与类型断言

### 空接口 `interface{}`（Go 1.18+ 可写 `any`）

```go
// 空接口可以接收任何类型（类似 Java 的 Object）
func printAny(v interface{}) {
    fmt.Println(v)
}

printAny(1)
printAny("hello")
printAny([]int{1, 2, 3})
```

### 类型断言

```go
var i interface{} = "hello"

// 方式 1：直接断言（失败会 panic）
s := i.(string)
fmt.Println(s)

// 方式 2：带检查的断言（推荐）
s, ok := i.(string)
if ok {
    fmt.Println("是字符串:", s)
}

// 类型 switch
switch v := i.(type) {
case string:
    fmt.Println("字符串:", v)
case int:
    fmt.Println("整数:", v)
default:
    fmt.Println("未知类型")
}
```

## 6. 接口组合

```go
type Reader interface {
    Read() string
}

type Writer interface {
    Write(s string)
}

// 接口组合
type ReadWriter interface {
    Reader
    Writer
}
```

## 7. 常用接口示例

### Stringer（类似 Java 的 toString）

```go
type Person struct {
    Name string
    Age  int
}

// 实现 fmt.Stringer 接口
func (p Person) String() string {
    return fmt.Sprintf("%s(%d)", p.Name, p.Age)
}

p := Person{Name: "Tom", Age: 18}
fmt.Println(p)  // Tom(18)
```

## 8. 实战示例：简单的支付系统

```go
package main

import "fmt"

// 支付接口
type Payment interface {
    Pay(amount float64) error
}

// 支付宝
type Alipay struct{}

func (a Alipay) Pay(amount float64) error {
    fmt.Printf("使用支付宝支付 %.2f 元\n", amount)
    return nil
}

// 微信支付
type WechatPay struct{}

func (w WechatPay) Pay(amount float64) error {
    fmt.Printf("使用微信支付 %.2f 元\n", amount)
    return nil
}

// 结算函数（依赖接口，不依赖具体实现）
func Checkout(p Payment, amount float64) {
    err := p.Pay(amount)
    if err != nil {
        fmt.Println("支付失败:", err)
        return
    }
    fmt.Println("支付成功")
}

func main() {
    Checkout(Alipay{}, 100.50)
    Checkout(WechatPay{}, 88.88)
}
```
