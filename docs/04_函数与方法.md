# 04 - 函数与方法

## 1. 函数定义

### Java 写法
```java
public int add(int a, int b) {
    return a + b;
}
```

### Go 写法

```go
// 基本定义
func add(a int, b int) int {
    return a + b
}

// 类型相同时可简写
func add(a, b int) int {
    return a + b
}

// 调用
sum := add(1, 2)
```

## 2. 多返回值（Go 特色）⭐

Go 函数可以返回多个值，这是 Java 没有的特性。

```go
// 返回多个值
func divAndMod(a, b int) (int, int) {
    return a / b, a % b
}

q, r := divAndMod(17, 5)
fmt.Println(q, r)  // 3 2

// 用 _ 忽略某个返回值
q, _ := divAndMod(17, 5)
```

### 命名返回值

```go
func swap(a, b int) (x int, y int) {
    x = b
    y = a
    return  // 自动返回 x, y
}
```

> 命名返回值会在函数开始时初始化为零值，函数内可直接使用，`return` 时自动返回。
> 命名返回值能让代码更清晰，但不要滥用。

## 3. 可变参数

```go
// 类似 Java 的 int...
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

// 调用
fmt.Println(sum(1, 2, 3))         // 6
fmt.Println(sum(1, 2, 3, 4, 5))   // 15

// 传入切片
nums := []int{1, 2, 3}
fmt.Println(sum(nums...))         // 6
```

## 4. 函数作为参数（闭包）

Go 中函数是一等公民，可以作为参数和返回值。

```go
// 函数作为参数
func apply(f func(int) int, x int) int {
    return f(x)
}

result := apply(func(n int) int {
    return n * n
}, 5)
fmt.Println(result)  // 25
```

### 闭包

```go
// 返回一个函数
func counter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

c := counter()
fmt.Println(c())  // 1
fmt.Println(c())  // 2
fmt.Println(c())  // 3
```

> 类比 Java：相当于 lambda 表达式和闭包，但 Go 的语法更简洁。

## 5. 方法（Method）

Go 没有 class，但可以给**类型**绑定方法。

### 给结构体绑定方法

```go
type Person struct {
    Name string
    Age  int
}

// 值接收者方法
func (p Person) SayHello() {
    fmt.Printf("Hi, I'm %s, %d years old\n", p.Name, p.Age)
}

// 调用
p := Person{Name: "Tom", Age: 18}
p.SayHello()
```

### 值接收者 vs 指针接收者 ⭐

```go
// 值接收者：不会修改原对象（拷贝）
func (p Person) SetAge1(age int) {
    p.Age = age  // 修改的是副本
}

// 指针接收者：会修改原对象
func (p *Person) SetAge2(age int) {
    p.Age = age  // 修改原对象
}

// 使用
p := Person{Name: "Tom", Age: 18}
p.SetAge1(20)
fmt.Println(p.Age)  // 18（没变）

p.SetAge2(20)
fmt.Println(p.Age)  // 20（变了）
```

### 选择原则

| 场景 | 接收者类型 |
|------|------------|
| 需要修改对象状态 | 指针 `*T` |
| 结构体较大（避免拷贝） | 指针 `*T` |
| 一致性（同一类型的方法最好统一） | 看情况 |
| 小结构体、只读 | 值 `T` |

> 实际开发中，**大部分情况用指针接收者**更安全。

### 调用语法糖

```go
p := Person{Name: "Tom"}
p.SetAge2(20)        // OK，Go 自动取地址 (&p).SetAge2(20)
(&p).SetAge2(20)     // 也 OK
```

## 6. 指针详解

```go
func modifyValue(n int) {
    n = 100  // 改的是副本
}

func modifyPointer(n *int) {
    *n = 100  // 改的是原值
}

x := 1
modifyValue(x)
fmt.Println(x)  // 1

modifyPointer(&x)
fmt.Println(x)  // 100
```

> 类比 Java：Java 中基本类型是值传递，对象是引用传递（其实也是值传递，传的是引用的副本）。
> Go 中所有传参都是值传递，但可以通过传指针达到"引用传递"的效果。

## 7. init 函数

每个包可以有一个或多个 `init` 函数，在 `main` 之前自动执行。

```go
package main

import "fmt"

func init() {
    fmt.Println("init 1")
}

func init() {
    fmt.Println("init 2")
}

func main() {
    fmt.Println("main")
}
// 输出顺序:
// init 1
// init 2
// main
```

> 用途：做包级别的初始化工作，比如读取配置、注册驱动等。

## 8. 练习

1. 写一个函数 `maxMin(nums []int) (int, int)` 返回切片的最大值和最小值
2. 给 `Person` 结构体添加 `Birthday()` 方法，让 Age +1
3. 写一个闭包，返回一个累加器函数
4. 实现一个简单的计算器函数 `calc(a, b int, op string) int`

```go
// 参考答案：计算器
func calc(a, b int, op string) int {
    switch op {
    case "+":
        return a + b
    case "-":
        return a - b
    case "*":
        return a * b
    case "/":
        if b == 0 {
            return 0
        }
        return a / b
    default:
        return 0
    }
}
```
