# Go 语言到 Gin 框架学习指南

> 适用对象：有 Java 基础的开发者
> 学习目标：掌握 Go 核心语法 → 学会 Gin Web 框架 → 能独立开发 RESTful API
> 学习原则：原理点到为止，重在动手敲代码

## 学习路线图

```
Go 基础 (01-06)  →  Go 进阶 (07-08)  →  数据库 (09)  →  Gin 框架 (10-13)  →  实战 (14)
```

## 学习建议

1. **每篇文档都要敲一遍代码**，不要只看
2. **遇到 Java 类似概念就对比**：Go 没有 class/继承/泛型（旧版），但有 struct/interface/组合
3. **每完成一个阶段做一个练手小项目**
4. **推荐学习节奏**：基础阶段 3-5 天，进阶 2 天，数据库 1 天，Gin 阶段 3-5 天
